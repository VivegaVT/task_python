# Discount Calculator
A simple, interactive graphical desktop application built with Python and Tkinter. This was made as part of a task.

# requirement
To run this application on your device, you will need to have python 3.x
No additional external libraries are required since `tkinter` comes pre-installed with standard Python distributions.

# How to Run Locally
You can run this application using your Command Prompt (CMD) 
1. download this python file
2. open command prompt
3. use "cd" command to change directory as needed
4. run it using "python discount_count.py"
   
# Using PyCharm
1. Launch PyCharm, click on File > Open, and select the discount_count.py file.
2. Make sure PyCharm is linked to your Python installation. 
3. Run the Code and the application window will open automatically!
